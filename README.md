# Ninjamp

Guitar amp simulator: a VST3 / AU plugin and a standalone app, for Windows and macOS.

**Download:** see [Releases](https://github.com/jmilthedude/ninjamp-releases/releases/latest).

- **Windows:** run `Ninjamp-<version>-Windows-Setup.exe`. It installs the VST3 plugin and the app. If Windows shows "Windows protected your PC", click **More info > Run anyway**.
- **Mac:** open `Ninjamp-<version>-macOS.pkg`. It installs the VST3 and AU plugins and the app. If macOS blocks it, open **System Settings > Privacy & Security** and click **Open Anyway**.

Close your DAW before installing. Ninjamp checks for updates itself: **Settings > Check for updates**.
